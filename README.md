# 南海トラフ津波 高さくらべ（高知県）

南海トラフ地震で想定される津波の高さと、津波が来るまでの時間を、自分の住む市町村で確かめられるWebアプリです。
数字だけでは実感しにくい「34m」や「3分」を、人や建物との比較、時間が進むバーで目に見える形にしました。

## できること

- **3D地図**：高知県の地図を斜め上から見下ろし、海岸線に沿って津波の高さの「壁」を立てます。壁の色と高さで、市町村ごとの津波の高さを比べられます。市町村をタップすると、その場所に寄って結果を表示します
- 高知県の沿岸19市町村から1つを選ぶと、次の情報を表示します
  - 最大津波高（m）
  - 1m・3m・5mの津波が来るまでの時間（分）
- **高さくらべ**：水面が0mから最大津波高まで上がるアニメーションで、人（1.7m）・2階建ての家（約6m）・3階建ての建物（約9m）と比べられます
- **3D表示**：「3D」ボタンで、同じ比較を立体で見られます。指でなぞると向きを変えられます
- **到達時間のバー**：「地震発生から◯分」の時計が進み、1m・3m・5mの津波が来た時点で印が赤くなります

## デザイン

- 3D地図を主役にしました。PC（幅960px以上）では左に地図を固定し、右の読み物だけがスクロールします。スマホでは見出し → 地図 → 結果の順に縦に並びます
- 色は、紙の白・墨・海の青を基本にし、朱色は危険や注意にだけ使っています
- 書体は、読みやすさを重視したユニバーサルデザイン書体（BIZ UDP明朝・BIZ UDPゴシック）を使っています
- 地図は、横になぞると回り、縦になぞるとページがスクロールします

## 見えにくい方・色の見え方が違う方への配慮

- 3D地図の壁は、明るさが段階的に変わる5色（薄い黄〜こげ茶）で塗り分けています。赤や緑が見分けにくい場合でも高低が分かるよう、主な色覚の型ごとに明るさの差を計算して確かめました
- 色だけに頼らず、凡例・ラベル・表で数字も示しています
- 画面読み上げ（スクリーンリーダー）向けに、地図や比較図に説明文を付けています。市町村を選ぶと、結果のまとめが読み上げられます
- 地図と同じ内容を、表（沿岸19市町村）でも見られます
- 端末で「動きを減らす」設定をしている場合は、アニメーションと自動回転を止めます。「時間の経過を見る」も最後の状態を表示します
- 「時間の経過を見る」を押すと、1mの津波が早く来る順を文字でも表示します
- ボタンは押しやすい大きさ（44px以上）にし、キーボード操作中の位置が分かるようにしています

## データについて

- 出典：内閣府（防災担当）「南海トラフ巨大地震モデル・被害想定手法検討会 地震モデル報告書 計算結果集 市町村別一覧表」（令和7年3月31日公表）
  - https://www.bousai.go.jp/jishin/nankai/kento_wg/pdf/ichiran.pdf
  - 利用条件：公共データ利用規約（第1.0版） https://www.digital.go.jp/resources/open_data/public_data_license_v1.0
- 地図：「国土数値情報（行政区域データ）」（国土交通省）を加工して作成。簡素化したデータは [スマートニュース メディア研究所](https://github.com/smartnews-smri/japan-topography) が公開しているもの
  - 海岸線は「隣の市町村と接していない境界線」として取り出しました
- 上記の資料をもとに、高知県の市町村の数値を抜き出して作成しました（編集・加工あり）
- 最大津波高：資料の「市町村別ケース別 最大津波高（満潮位・地殻変動考慮）」の「最大値」（ケース①〜⑪のうち最大）
- 到達時間：資料の「市町村別 津波到達時間（津波高+1m／+3m／+5m）」の「①～⑪の最短時間」

## 注意

- 3D地図の壁の高さは、見やすくするため実際の250倍にしています。壁は浸水する範囲を表すものではありません
- 表示している数値は想定であり、実際の津波とは異なる場合があります
- 数値は市町村ごとに1つにまとめたものです。自宅など個別の場所の値ではありません
- 避難の判断には、お住まいの自治体のハザードマップや、気象庁の津波警報などを使ってください

## 自分のPCで動かす方法

data.json を fetch で読み込んでいるため、index.html をダブルクリックで開くとデータが表示されません。
VS Code の拡張機能「Live Server」で開くか、GitHub Pages の公開URLで確かめてください。
